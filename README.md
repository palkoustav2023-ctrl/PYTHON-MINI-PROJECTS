# PYTHON-MINI-PROJECTS
I created this repository for showing you my developed python mini projects.

**ATM.py:**
What this program do?
This program is a program of using a working ATM system. In this program, the user can add username, pin and balance according to his/her need. The program will check further that what condition is met. There are options to deposit money, withdraw money, check balance or exit the program.

**ROCK, PAPER, SCISSORS.py:**
What this program do?
In this program, computer takes a random choice of rock or paper or scissors, user also gives their choice as input. Basically it is a game of rock, paper, scissors of user with computer.
